# FR5 기본 집기 실험

FR5에 검증용 평행 그리퍼를 추가해 블록에 접근하고, 들어 올려 운반한 뒤 내려놓는
독립 MuJoCo 시뮬레이션입니다. 기존 ROS 조작 화면의 TCP Pose 계획과는 실행 경로가 다릅니다.
이 실험은 Python MuJoCo 3.14.0과 로컬 site-Jacobian DLS를 사용합니다.
기존 ROS native 3.12.0의 그리퍼 제어·MoveIt 장면 부착 연결은 후속 통합 항목입니다.

## 실행과 3D 관측

먼저 기존 FR5·UR5e 작업 환경의 모델을 생성합니다. `--source`는 이 작업 환경의
생성 디렉터리이며, `--output`은 아직 존재하지 않는 새 디렉터리여야 합니다.

```bash
PYTHONPATH=src .venv/bin/python -m mujoco_ros2_manipulation.grasping.demo_server \
  --source runtime/generated/workcells/fr5_ur5e \
  --output runtime/grasp-demo/my-first-run --port 8918
```

패키지 설치 후에는 같은 인수를 `manipulation-grasp-demo`에 전달할 수 있습니다.
출력한 로컬 주소를 열고 **정해진 FR5 집기 시연 실행**을 누르면 새로운 물리 실행을 시작합니다.
저장한 영상의 재생이 아닙니다. Three.js는 실행에서 관측한 팔·손가락·자유 물체의 형상을 표시합니다.
한 서버는 한 작업만 실행하며, 이전 작업이 종료·정리된 뒤 새 작업을 시작할 수 있습니다.
브라우저에서 임의의 모델 경로·목표·명령을 전달하는 기능은 없습니다.

화면은 다음 정보를 구분합니다.

- 접근, 그리퍼 닫기, 들어 올리기, 집기 확인, 이송, 놓기, 안정화 단계
- 양쪽 손가락 접촉력과 TCP·블록의 실제 위치
- 물리 집기와 논리 부착 기록, 상대 위치·각도 오차
- 작업 결과, 취소 전달, 프로세스 종료와 물리 정지 관측
- 관측 시각·나이, 실행 세대와 모델 SHA

취소를 관측하면 다음 물리 적분과 작업 단계를 중단합니다. 정착한 유지 구간을 관측하지
않으므로 프로세스가 종료됐다는 이유로 물리 정지가 확인됐다고 표시하지 않습니다.
취소 후 자동 놓기나 자동 재개를 수행하지 않습니다. 서버를 종료하면 자체 소유한 작업만 정리합니다.

## 집기와 부착 판정

실행 중인 물체는 자유 물체입니다. 물체를 손끝에 용접하거나, 매 스텝 물체 자세를 덮어써서
집기를 표현하지 않습니다. 원래 FR5의 관절·관성·위치 서보·토크 제한을 복사한 별도 모델에서
6축 동역학과 손가락 접촉을 적분합니다.

| 판정 | 사용하는 관측 |
| --- | --- |
| 양쪽 접촉 | 양쪽 손가락의 접촉력과 관측 기간 |
| 물리 집기 | 들어 올린 높이, 상대 자세 변화, 양쪽 접촉 유지 |
| 논리 부착 | 물리 집기 확인 후 기록하는 객체·소유 공구·링크 |
| 운반 | 상대 위치·각도 오차와 양쪽 접촉 유지 |
| 놓기 | 접촉력 감소, 손가락 열림, 테이블 접촉과 물체 위치·속도 |

논리 부착은 작업 상태의 기록입니다. MuJoCo 구속 조건이나 MoveIt Planning Scene을
변경하지 않습니다. 의도한 손가락–물체·물체–테이블 접촉만 단계별로 허용하고,
나머지 관측 접촉은 다음 적분 전에 실패로 처리합니다. 기존 ROS 장면의 전체 접촉 정지 정책을
이 실험 때문에 완화하지 않습니다.

## 보존과 재생

각 실행은 새 작업 디렉터리에 모델·메시 해시, 실행 소스 사본과 해시, 관측 프레임,
단계·접촉·결과, 소유 프로세스 종료 기록을 보존합니다. 실패 결과도 덮어쓰지 않습니다.
팔 관절 6개의 단위는 rad, 손가락 슬라이드 2개의 단위는 m입니다.
자유 물체는 위치와 단위 쿼터니언을 포함한 전체 qpos로 보존합니다.

`manipulation-grasp-export --help`로 보존 결과의 표시 기록 변환 인수를 확인합니다.
변환기는 별도 데이터에서 `mj_forward`로 형상을 복원하며 물리를 적분하지 않습니다.
기존 공통 표시 형식의 형상 변환을 사용하므로 손가락 이동이나 자유 물체를 가짜 회전 관절로
만들지 않습니다. 결과를 일반 기록 뷰어에서 재생할 때는 새 물리 실행과 구분합니다.

## 현재 확인한 범위

독립 Cartesian 시험에서는 정상, 물체 없음, 한쪽 접촉, 미끄러짐, 취소, 예상 밖 접촉을
검사했습니다. FR5 대표 사례에서는 접근·집기·인출·80 mm 운반·해제·안정화를 확인했습니다.
초기 FR5 사례의 후퇴 중 손가락–테이블 접촉 실패도 보존했고, TCP·패드 간격과 서보 시작점을
수정한 후 대표 사례를 다시 확인했습니다.

이 결과는 한정된 모델·블록·고정 순서의 개발 검증입니다. 임의 물체의 집기 성공률,
충돌 없는 전역 경로, 실제 그리퍼나 실물 로봇의 성능을 평가한 결과는 아닙니다.
기존 ROS 경로의 공구 기하, 그리퍼 제어기, 자유 물체, 허용 접촉, 계획상 부착의 통합을
완료한 것으로 합산하지 않습니다.
