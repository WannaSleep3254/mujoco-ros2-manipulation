# 로봇 시뮬레이션 시스템 통합 작업리스트

2026-10-29 개정 1.10 · 작업 시작 기반 [`main 61e55ba`](https://github.com/WannaSleep3254/mujoco-ros2-manipulation/tree/61e55ba7040910bb25758b6310e353f35ed92b6f) · W01~W06 기록 보존 · W07 ROS 집기·관측 전달과 팔 내부 간격 검증

로봇의 동작을 시뮬레이션하고 검증하는 환경을 만들기 위한 작업리스트입니다. 완료한 뷰어 개선과 실행 기능을 출발점으로, 남은 신뢰성 문제를 확인하고 구성 요소를 점진적으로 분리합니다. 새로운 레퍼런스의 제안은 기대 효과와 변경 규모를 함께 평가해 반영합니다.

## 개발 방향

- **구성 요소 교체:** 로봇 모델, 시뮬레이터, 모션 플래너, 제어 인터페이스와 뷰어를 각각 교체하거나 확장할 수 있도록 구성합니다.
- **설치 환경 반영:** 현장 설비의 설계 파일과 배치를 작업 환경에 반영합니다.
- **동작 검증:** 구성한 환경에서 계획, 실행 결과, 충돌과 실패 원인을 확인하고 기록합니다.

현재는 MuJoCo·ROS 2·MoveIt 2로 동작 검증 기능을 개발합니다. ROS 2는 익숙한 개발 스택과 센서 SDK 연계의 활용성을 고려한 현재 구현 수단입니다. Three.js는 유지하고 공통 형상·상태·센서 공급원을 확장합니다. FAIRINO FR5·FR10과 UR5e는 초기 테스트 기준이며, 기능이 안정되면 지원 로봇을 늘립니다.

비공개 QML 로컬뷰어의 설계 파일 처리와 별도 설비 공정의 개발 일정은 각각 관리합니다. 공통 좌표·자산·상태 규약은 필요에 따라 맞추되, 각 프로젝트의 작업 순서를 이 목록에 그대로 가져오지 않습니다.

## 2026-10-28 5~6단계 진행

사용자가 선택한 첫 집기 대상은 FR5·검증용 평행 그리퍼·단순 블록입니다. W07을 먼저 진행하고,
대표 작업과 실패 규칙을 확인한 뒤 W08 성능 비교, W09 로봇 확대 순서로 이어갑니다.
사용자는 독립 집기 시연을 먼저 정리한 뒤 6단계로 진행하도록 선택했습니다.
기존 ROS 경로의 그리퍼·접촉·자유 물체·MoveIt 부착 통합은 후속 작업으로 분리합니다.

- **TCP Pose 계획:** 기존 ROS 장면의 끝단 원점 참조를 등록하고 별도 Pose 계획 요청,
  IK/FK 확인, 선택 팔 계획과 다른 팔의 전체 spline 유지, 일회 승인 실행을 연결했습니다.
  관절 성공과 별도로 실행 후 TCP 완료 조건을 확인합니다. [조작 안내](operator_console.md#tcp-pose-목표와-완료-확인)에 현재 범위를 정리했습니다.
- **물리 집기:** 독립 MuJoCo 3.14 모델에서 평행 그리퍼와 자유 물체의 정상·실패 조건,
  실제 FR5 6축 동역학의 대표 집기와 해제를 확인했습니다. 기존 ROS native 3.12·MoveIt의
  그리퍼 제어·허용 접촉·물체 부착 연결을 완료한 결과로 합산하지 않습니다.
  실제 관측한 손가락과 물체 상태를 별도 [3D 실행 화면](grasping.md)에 연결했습니다.
  실제 HTTP 정상 실행과 이송 중 취소, 브라우저 실행·취소·휠 확대와 좁은 화면 배치를 확인했습니다.
- **UI/UX:** 1~4단계에서는 기능별 실제 UI 수정과 최초 HTML 시안 제작을 진행했으나,
  별도 시안의 후속 갱신과 전체 배치 통합은 이어가지 못했습니다. 이번에 별도 시안 v1.1·v1.2를
  갱신했고, 실제 Pose 계약·완료 오차와 독립 집기 화면을 대조했습니다. 가상 데이터 시안과
  실제 연결 검수 결과를 구분하며, 시안 전체 레이아웃을 적용했다고 판정하지 않습니다.

W07의 독립 첫 버전은 PR #55의 CI 6개를 통과해 devel에 병합했습니다. W08은 실제 기능 10조건과
성능 12표본, 기존 Pose 회귀를 확인하고 [비교 보고서](operator/planner-cache-2026-10-28/index.html)에
정리했습니다. W09는 잠긴 FAIRINO FR3 V6 자산으로 모델·실행·취소·종료와 표시를 검증합니다.
FR3는 실제 direct·MoveIt·이동 중 취소·신선한 정지 관측·홈 복귀·native·종료와
읽기 전용 뷰어 표시의 대표 로컬 검증을 마쳤습니다. [FR3 문서](fr3-model.md)에
실패 두 건과 수정 결과를 보존했습니다. 전체 ROS 집기 통합과 넓은 FR3 작업 범위는 후속입니다. 첫 TCP 완료 오차 초과,
독립 FR5 시연의 접촉 실패와 이후 수정 결과를 각각 보존합니다. W01의 과거 간헐 종료 지연
원인과 넓은 반복 평가도 열린 항목으로 유지합니다.

main 후속 검사에서 닫기 목표 전 원본 관측이 0.5초를 넘어 차단된 기록을 보존했습니다. 정확한 지연 구간은 기존 기록만으로 확정하지 않았습니다. 큰 파일의 동기 검사로 관측 처리가 지연될 수 있는 경로를 별도 소유 프로세스로 옮기고, 새 실제 실행에서 검사 중 새 관측 수신과 한 번의 목표 전송, 취소·정리를 확인했습니다. [실행 전 검사 후속 근거](operator/system-direction-2026-10-27/grasp-admission-verification.json)에 원본과 지연 주입·실제 실행을 구분합니다.

- [ ] 브라우저 요청부터 실제 이동·정착까지의 전체 체감 지연 평가

## 2026-10-29 센서·3D 기록 재생

동일 실행의 관절 원천 시각과 RGB8 acquisition stamp를 보존하는 기록과 공통 재생 화면을 추가했습니다. 실제 ROS 도메인 228에서 자세 41개·이미지 18개의 대표 기록을 생성하고, 내부 영상 누락·원천 시각·불변 이미지 해시·탐색 후 명령 재전송 없음을 확인했습니다. 첫 시험에서는 누락 전에 이미지를 수집하지 않아 내부 누락 검증에 실패했으며, 원본을 보존하고 해당 시험 조건을 수정했습니다. 진단 패턴 입력이며 실제 카메라 동기화 정확도나 장시간 성능 결과는 아닙니다.

이후 진행한 기존 ROS 경로의 그리퍼 제어·자유 물체·허용 접촉·MoveIt 부착 연결 결과는 [W07](#w07-기본-작업-단위)에 정리했습니다. 독립 집기 시연의 성공을 ROS 통합 결과로 합산하지 않습니다.
