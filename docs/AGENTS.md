# 리포트 작성 기준

새 HTML 개발 사례·기술 설계·방향성 리포트는 `reporting/report-style-guide.md`의 v1.9 기준과 `reporting/templates/engineering-report-v1.9.html` 템플릿을 기본으로 사용합니다. 기준 구현은 `operator/viewer-direction-2026-10-22/index.html`입니다.

- 요약 → 현재 구현과 근거 → 대안 → 단계별 개선 → 비교 검증 → 한계 → 출처 순서로 작성하고, 내용에 필요하지 않은 모듈은 제거합니다.
- 역할·기준·후보 식별자만 항목명+설명 구조를 사용합니다. 기능·작업은 일반 목록, 순서가 필요한 절차는 번호 목록으로 씁니다.
- 현재 구현, 검증 사실, 설정값, 설계 제안, 미측정 범위를 명시적으로 구분합니다. 모르는 수치나 결과는 만들지 않습니다.
- 설명문은 합니다·입니다 체, 짧은 제목·완료 조건은 명사형으로 씁니다. 그림·표·도식은 유형별 번호와 짧은 제목을 붙입니다.
- 문서에 필요한 자산만 상대 경로로 묶고 PC·모바일·인쇄와 링크·근거 해시를 확인합니다.
- 기존 측정 보고서의 `report.json` 스키마·표본·원본·자동 생성 계약은 유지합니다. HTML 양식 채택을 이유로 과거 측정이나 생성 파일을 직접 재작성하지 않습니다.
