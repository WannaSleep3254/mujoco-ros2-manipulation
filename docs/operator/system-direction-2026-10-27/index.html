Project overview

교체 가능한 동작 검증 환경

현재 기능을 유지하면서 로봇 모델·물리 엔진·계획기·제어 인터페이스·뷰어의 교체 경계를 단계적으로 정리합니다.

개발 방향
현장 설비의 설계 파일과 배치를 반영하고, 같은 환경에서 계획·실행·충돌·실패 원인을 확인하고 기록합니다.
구현 상태
FR5·FR10·UR5e 단일 모델과 FR5·UR5e 공동 물리, 요청별 실행·취소·계측, Three.js 조작 화면을 구현했습니다. 다른 엔진과 범용 센서의 실제 연결은 후속 작업입니다.
도입 배경
계획한 경로와 실행 상태를 연결해 실패를 설명하고, 설치 환경이나 모델이 달라져도 필요한 부분을 바꾸어 검증할 수 있어야 합니다.
구현 방식
MuJoCo·ROS 2·MoveIt 2로 동작 검증을 개발합니다. ROS 2는 익숙한 개발 스택과 센서 SDK 연계의 활용성을 고려한 현재 수단입니다. Three.js는 유지하며 공통 형상·상태·센서 공급원을 확장합니다.

현재 우선순위

  • 취소 후 정리 지연과 기둥 접촉 사례의 원인 진단
  • 원인에 맞춘 수정과 실행 회귀 기준 확보
  • 작업·계획·실행의 공통 규약과 설치 환경 연결

확장 기준

  • FR5·FR10·UR5e를 초기 테스트 기준으로 사용
  • 안정된 생성·실행·취소·종료 규약으로 지원 로봇 확대
  • 기대 효과·변경 규모·선행 조건으로 새 제안 선별
현재 사실기준 코드·기존 기록확장안후속 구현미검증추가 진단·평가

실행할 세부 항목과 상태는 통합 작업리스트에서 관리합니다. 이 보고서는 2026-10-27의 작업 순서와 선택 근거를 보존합니다.

01 / Current implementation

현재 구성과 완료 범위

모델·환경
RobotProfile·Workcell과 생성 자산 해시, 이름 기반 관절·설치 자세를 공유합니다. 프로필과 생성기는 ROS·MuJoCo·제어기 설정에 아직 연결되어 있습니다.
계획·검사
현재 상시 서버가 MoveIt 계획·유효성 검사, 출발 시점 탐색, 최종 spline 검사와 실행을 연결합니다. 제한된 후보 중 처음 통과한 경로를 선택하며 최단 경로를 보장하지 않습니다.
실행·기록
ROS 2의 FollowJointTrajectory로 팔별 궤적을 전달합니다. 요청 ID·중복 처리·취소·완료·추종 상태를 기록하고, MuJoCo 접촉·시계 인터록을 유지합니다.
표시·분석
별도 표시 작업자가 만든 형상·상태를 Three.js로 표시합니다. 공통 표시 형식과 ROS 없는 읽기 전용 기록 재생을 구현했습니다. 표시용 모델은 제어용 물리 시뮬레이션과 역할이 다릅니다.

현재 서버의 결합을 점진적으로 분리하는 계획입니다. 범용 Planner·Executor·Simulator 플러그인이나 ROS 2 없는 로봇 실행을 이미 제공한다는 의미는 아닙니다. 공통 모듈 경계에 현재 결합을 기록했습니다.

02 / Open evidence

원인 확인이 필요한 두 사례

취소 후 정리 지연

관측 사실 과거 비교 시연의 취소가 중첩 실행까지 전달됐지만 최종 종료·정리가 지연된 사례가 있습니다.

미확정 정확한 대기 호출과 자원 수명 문제는 확정하지 않았습니다. 노드 해제·ROS 종료·소유 launch 종료·작업자 대기의 진행 시각과 스택을 연결해 W01에서 진단합니다.

공개 CI 실행 기록 · 취소 수신, 정지 확인, 작업 종료, 프로세스 종료를 각각 판정합니다.

기둥 근처 실행 접촉

관측 사실 기둥과 약 1.8 mm 떨어진 명목 경로가 검사를 통과한 뒤 실행 상태에서 접촉하여 네이티브 인터록이 정지한 사례가 있습니다.

원인 후보 작은 환경 여유와 추종 차이의 조합을 의심합니다. 검사·전송 궤적의 일치, 형상 근사·표본 간격·실제 상태를 대조하기 전에는 기여도와 빈도를 단정하지 않습니다.

공개 CI 실행 기록 · W02 진단 뒤 W03에서 원인에 맞게 수정합니다.

현재 팔 사이 30 mm 계획·20 mm 관측 기준은 설비 전체와의 공통 여유가 아닙니다. 이산 표본·형상 근사 검사는 연속 시간이나 실물의 안전 인증으로 해석하지 않습니다. 수정 효과는 고정 입력과 인접 조건에서 확인하고, 재실행 성공만으로 과거 실패를 닫지 않습니다.
