단순 출력 화면에 조작·검토 기능 추가

서버의 2D 이미지 스트리밍 화면에서, 브라우저가 3D 모델을 직접 렌더링하고 계획을 확인하는 화면으로 확장되었습니다.

초기 WebGL에서는 시점을 직접 조작할 수 있게 했습니다.
현행 버전은 표시할 모델과 실행 대상을 구분하고, 계획 검토·승인·이력 연결과 형상 탐색을 지원합니다.

포트 번호는 개발 버전이 아닙니다.

현재 운영 상태와 구분: 아래 화면과 서버 정리는 10월 27일의 기록입니다. 10월 30일 조사한 여섯 뷰어의 역할·실행 상태와 새 동작 영상은 현재 뷰어 상태 리포트에서 확인합니다. 기존 영상을 새 구현이나 같은 조건의 성능 비교로 바꾸어 해석하지 않습니다.

Scope & limitations

이 자료로 확인할 수 있는 범위

  • 새 영상은 카메라·로컬 표시 기능과 촬영 당시 화면을 기록합니다. 새 로봇 실행이나 새로운 경로·접촉 검증을 수행한 자료가 아닙니다.
  • 세 단계의 UI·시점·자세·실행 세션은 다를 수 있습니다. 픽셀 품질, 종단 지연, 동일 작업 성공률의 비교 자료가 아닙니다.
  • 8765·8890의 적재된 백엔드 코드 전체 버전은 미확정입니다. 신규 운영 기록과 고정 Git 기준의 기능 설명을 구분합니다.
  • 기존 취소 정리의 간헐적 CI 실패와 기둥 근접 경로의 접촉 사례는 이 화면 정리로 해결되었다고 주장하지 않습니다.
