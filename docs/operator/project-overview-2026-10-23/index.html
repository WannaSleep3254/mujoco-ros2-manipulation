MuJoCo·ROS 2를 사용하는 이유

초기 장비와 실행 환경을 고려해 MuJoCo로 개발을 시작했습니다.
ROS 2는 기존 개발 스택과 개발자 선호, 다양한 센서·SDK의 연계 활용을 고려해 선택했습니다.
