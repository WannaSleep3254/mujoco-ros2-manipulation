평가 범위와 판정

예비 평가

FR5·UR5e의 고정 초기·목표 상태에서 공간 후보 상한 1과 12를 공통 5wall초 예산으로 비교했습니다. 정상 목표의 동작·계획 실패와 의도한 무효 목표 거부를 분리합니다.

  • 고정 사례 10개 중 정상 목표 9개와 부정 대조 1개를 분리했습니다. 사례·조건당 예정 반복은 1회입니다.
  • 후보 상한 1: 정상 목표 선택 7회, 동작 성공 5회, 계획 실패 2회, 추적 확보 7회. 성공 중 후속 후보 선택 성공 0/5회입니다. 부정 대조는 기대한 invalid_goal 거부 0/0회로 별도 집계합니다.
  • 후보 상한 12: 정상 목표 선택 7회, 동작 성공 6회, 계획 실패 1회, 추적 확보 7회. 성공 중 후속 후보 선택 성공 0/6회입니다. 부정 대조는 기대한 invalid_goal 거부 0/0회로 별도 집계합니다.
  • 완료된 동작 성공 11회는 모두 첫 후보를 선택했습니다. 이 측정에서 후속 후보에 의한 회복 성공은 관측되지 않았습니다.
  • 고정 시작 자세에서 홈 복귀: 선택한 2회 모두 추적을 확보했으나 동작 성공은 없었습니다. 계획 실패 2/2회, Action 전송 0개입니다. 이 고정 입력·예산·후보 정책에서의 결과이며 전역적으로 해가 없음을 뜻하지 않습니다.
  • 전체 예정 20행을 보존했습니다. 발행 시도 14, 추적 확보 14, 미실행 6, 검증 실패 0행입니다.
  • 같은 고정 입력을 각 조건에서 별도 계획했으며, 계산·경로 표의 차이만으로 후보 상한의 성능 우열을 확정하지 않습니다.

해석의 한계

  • 선택 일부·반복 부족 또는 중단된 진단 실행입니다. 예정된 전체 60행 평가의 완료 결과로 취급하지 않습니다.
  • 소수의 고정 FR5·UR5e 사례를 같은 기구·준비 절차에서 반복한 예비 평가입니다. 사례 간 상관이 있으며 일반 로봇·장애물·모션플래너의 성능으로 확대하지 않습니다.
  • 사례·조건당 예정 n=1이며 존재하는 값만 중앙값으로 표시합니다. p95/p99·신뢰구간·통계적 유의성을 주장하지 않습니다.
  • 조건 간 OMPL/RRT의 내부 난수·최초 제안 경로를 고정하거나 공유하지 않았습니다. 둘 다 첫 후보를 고른 경우에도 시간·경로 차이가 날 수 있어 상한 변경의 인과 효과와 분리해야 합니다.
  • 초기 상태는 명목값에서 최대 0.0015rad 이내로 맞췄습니다. 초기화·보정·warmup·시뮬레이터 시작은 요청 지표에서 제외하며 서로 다른 시작 상태·시계의 과거 리포트와 직접 합산하지 않습니다.
  • 계획 최소 간격은 완전 경로와 부분 경로를 구분합니다. 부분 경로의 prefix 최소값을 전체 경로 최소값으로 사용하지 않으며 native 샘플 검사는 연속 시간 또는 실제 장치 안전 인증이 아닙니다.
  • 계산 예산은 blocking 호출을 강제로 중단하는 실시간 deadline이 아닙니다. 실제 초과와 실패를 포함해 기록하며 미실행·발행 후 결과 불명 요청은 근거에서 숨기지 않습니다.
  • 공개 근거는 원본 SHA와 선별한 수치·구성만 보존합니다. 전체 곡선은 포함하지 않아 이 공개 자료만으로 기하 재평가를 수행할 수 없습니다. 원본 runtime 경로·프로세스 명령·개인 식별값·원문 오류 메시지는 공개하지 않습니다.
  • 측정 시 작업 트리에 변경이 있었습니다. 표시 커밋만으로 실행 소스를 재구성할 수 없으며 공개 근거의 측정 당시 implementation SHA를 함께 확인해야 합니다.
