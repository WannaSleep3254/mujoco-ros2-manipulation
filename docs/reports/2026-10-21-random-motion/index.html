평가 범위와 판정

예비 평가

FR5·UR5e의 근거리 랜덤 목표 5개를 두 전략으로 실행한 재현 평가. 전체 작업 공간 성능평가가 아닙니다.

  • 목표 5개 × 2전략. seed 20261021, 반경 0.6rad, 같은 계산 예산 5.0wall초.
  • 양팔 공동 계획: 성공 5/5, 실패 0. 실패 요청도 원본과 분모에 포함.
  • 독립 계획 + 출발 조정: 성공 5/5, 실패 0. 실패 요청도 원본과 분모에 포함.
  • 기준 실측 자세 대비 시작 허용오차 0.0015rad. 명목 홈·실측 기준·각 요청 시작 상태를 보존.
  • 복귀·워밍업 16개 요청을 별도 보존하고 점수에서 분리. 한 시뮬레이터 정상 종료, 접촉 0스텝.
  • 랜덤 출발 조정 5회에서 선택 지연은 모두 0sim초. 교차 전용 탐색은 별도 표본으로 구분.
  • 별도 교차 입력 탐색: 후보 58개, 거리 39917회, 전체 1.966wall초. 선택 지연 2.3sim초는 계산 시간과 구분.

해석의 한계

  • 홈 주변 관절 목표의 소규모 표본. Cartesian/TCP 작업, 교차 전용 과제, 전역 작업 공간의 성공률로 일반화할 수 없음.
  • 목표 생성 seed는 고정하지만 OMPL 내부 난수열과 OS 스케줄링을 고정하지 않음. 같은 입력도 경로와 시간은 달라질 수 있음.
  • 최초 이동은 /joint_states 수신의 0.001rad 초과 변화이며 1초 sim 예약을 포함. 시뮬레이터 시작 비용은 제외.
  • 예산은 상태 스냅샷 후 계획·탐색·최종 검사·상태 재확인까지의 협력식 wall 제한. 이미 진행 중인 RPC/native 호출을 선점하지 않아 초과 시간이 기록될 수 있음.
  • 성공 요청의 지연·경로 표본 수와 전체 요청 분모는 다를 수 있음. p95/p99 또는 통계적 신뢰 구간을 제시하지 않음.
  • MuJoCo convex 근사·이산 거리 검사 결과. 실제 하드웨어·공구 TCP·연속 시간 안전 인증을 검증하지 않음.
  • 이번 랜덤 목표의 교차 대기·회피 난이도는 낮음. 다양한 교차·장애물 조건의 회피 성공률은 추가 평가가 필요함.
  • 별도 고정 교차 탐색은 현재 모델에서 새로 검증·고정한 입력 1회. 과거 1차의 다른 궤적·환경과 직접 속도 향상을 비교하지 않음.
